# Ананасовый улун · Чайный Бум

Верхняя часть карточки товара по тестовому заданию Teaboom. **HTML5, CSS, vanilla JavaScript, Grid/Flexbox.** Без Bootstrap, готового шаблона и runtime-зависимостей.

## Быстрый запуск

Откройте **`index.html`** в современном браузере. Все изображения, стили, скрипты и шрифты локальные; интернет для работы карточки не нужен.

Или, с Node.js 20+, из корня проекта:

```bash
npm start
```

Страница: **http://localhost:5173**. Для запуска сервера `npm install` не требуется. Остановка: `Ctrl+C`.

Альтернатива с Python 3: `python3 -m http.server 5173`.

## Что реализовано

- Изображение, название, категория, четыре фасовки, артикул, текущая и старая цены, кнопка и короткое описание.
- На обычной загрузке и перезагрузке выбрана **100 г**. При переключении обновляются обе цены, артикул, скидка, выгода и выбранное состояние.
- **Один JS-объект `variants` в `js/product.js`** содержит полный прайс-лист. Цены хранятся в целых копейках. `Intl.NumberFormat('ru-RU')` сохраняет две цифры после запятой у дробных сумм и разделяет тысячи у целых.
- Старая цена, скидка и выгода скрыты, если скидки нет. Процент округляется до целого.
- Кнопка имеет `type="button"`, состояния hover, focus-visible, active и временное «Добавлено». Показывает только демо-уведомление. **Реальная корзина, API, backend и оформление заказа не подключены.**
- Нативные radio-input в `fieldset/legend`, переключение стрелками, видимый фокус, live-region и ссылка пропуска навигации.
- Фото увеличивается в нативном `dialog`; закрытие кнопкой, по фону или `Escape`, возврат фокуса.
- Меню компактно на планшете и телефоне. Внешние ссылки открывают действующий Teaboom в новой вкладке.
- При отключённом JavaScript остаётся статическая карточка 100 г и пояснение; неработающие элементы отключены.

## Визуальный стиль

Оформление приближено к действующему Teaboom, в том числе [странице «Свежая ромашка»](https://teaboom.ru/product/chaj-zelyonyj-svezhaya-romashka). Товар, четыре фасовки и все цены остаются из задания на **«Ананасовый улун»**.

- Оригинальный ненавязчивый чайный паттерн, сохранённый локально в lossless WebP.
- Заголовок 32 px / 700 над фотографией и покупкой, а не крупный рекламный заголовок справа.
- Красная цена и компактный светло-серый блок покупки; зелёная кнопка сохранена.
- Двухрядная шапка: кремовая полоса бренда/контактов и белая навигация с жёлтым акцентом.
- Жёлтый элемент ведёт в реальный каталог; это ссылка, а не неработающий поисковый input. Поисковый API не подключён.
- Плоское оформление: скругления 0–2 px, без крупных округлённых карточек. Тёмный заголовок описания и кремовая подложка повторяют цветовую логику исходного сайта.

## Адаптивность и код

- **1440 px:** заголовок над двумя колонками, фото слева, компактная покупка и описание справа.
- **768 px:** заголовок над двумя компактными колонками, описание под ними на ширину контейнера.
- **375 px:** заголовок → фото → покупка → описание → заваривание. Четыре фасовки помещаются в ряд без обрезания подписей.
- Основной текст и фасовки — 14 px, вторичные подписи — 12 px; подпись бренда — 11 px.
- Классы в стиле BEM; цвета, отступы, размеры контролов и скругления заданы CSS-переменными. Отступы используют единую 4 px шкалу. Размеры рамок, иконок и контрольные ширины экрана — явные параметры геометрии, не ручное позиционирование карточки.
- В исходном HTML нет атрибутов `style`; CSS и JavaScript находятся в отдельных файлах.
- Локальные WebP 480/970 px, `srcset`/`sizes`, заданные размеры фото, Open Sans и поддержка `prefers-reduced-motion`.

## Автотесты

Зависимости устанавливаются **только для тестов**, а не для страницы:

```bash
npm ci
npx playwright install chromium
npm test
```

На Linux при отсутствии библиотек браузера: `npx playwright install --with-deps chromium`.

Тесты проверяют все четыре фасовки, цены, артикулы, скидки, выгоду, выбор по умолчанию, клавиатуру, UI-состояния, отсутствие горизонтального переполнения и сетевых запросов при добавлении. Также выполняются автоматические проверки доступности через axe-core. Автотесты не заменяют ручную проверку на физических устройствах.

## Автономный файл и публикация

`npm run export` создаёт **`teaboom.html`** со встроенными ресурсами для передачи и офлайн-просмотра. Это дополнительный экспорт; исходники остаются раздельными.

Для **GitHub Pages** загрузите содержимое папки `teaboom-product/` в корень репозитория, затем **Settings → Pages → Deploy from a branch → main / root**. Все локальные пути относительные, поэтому страница работает в подпапке репозитория. На хостинг достаточно передать `index.html`, `css/`, `js/`, `img/`, `assets/`; Node.js на хостинге не нужен.

Публичная страница пока не опубликована. Самодостаточный HTML и live-превью не заменяют постоянную публичную ссылку.
